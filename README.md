 Анализ отзывов с Кинопоиска с использованием BERT

 Этот проект посвящён анализу тональности отзывов с сайта Кинопоиск на русском языке с помощью моделей на основе BERT. 
 Цель — классифицировать отзывы положительные, нейтральные или отрицательные, используя современные методы обработки естественного языка (NLP).

 Структура проекта
 * kinopoisk-bert.ipynb — основной Jupyter Notebook с обучением
 * requirements.txt — список зависимостей проекта
 * get_urls.py - скрипт для получения ссылок на фильмы из популярных (selenium)
 * parser.py - скрипт для парсинга ссылок (selenium)

Данные собранные мной лежат https://www.kaggle.com/datasets/halssara/kinopoisk-reviews
